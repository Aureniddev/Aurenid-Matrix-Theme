# 💀 Aurenid World — Custom Terminal Theme

Welcome to the official repository for **Aurenid World**, a high-tech terminal style overhaul designed for Discord via Vencord.

---

## 🎨 Design System
* **Core Interface Layout:** Dominated by Cyber Crimson Red (`#FF0036`) across all client channels, server panels, user sliders, and main system badges.
* **Network Links:** Glowing Neon Cyan (`#00F0FF`) web anchor links that instantly shift to crisp white when hovered over with a mouse pointer.
* **Atmosphere:** Clean monospaced terminal font matrix styling with soft background image blurring.

---
